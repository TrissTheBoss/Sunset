# First Cline task

Use this task after adopting the handbook as the active repository specification.

> Implement M0 and only the smallest runnable portion of M1. Read AGENTS.md, the PRD, parity standard, roadmap and current progress. Inspect the existing checkout and Git status before edits. Preserve user changes.
>
> Confirm the approved fresh-tree replacement state; do not silently reuse the old engine. Verify the locally installed Java Edition target and record artifact hashes/protocol/pack/data versions without committing game bytes or secrets. Detect OS/CPU/GPU and record unknowns explicitly. If legal assets are absent, support synthetic fixtures and return BLOCKED for reference-dependent tests.
>
> Pin a real installed/tested Rust toolchain and compatible dependencies. Create a minimal safe Rust workspace and xtask doctor/report foundation with versioned result schema, noninteractive failure codes and isolated output paths. Add a synthetic fixture and one intentionally failing harness self-test to demonstrate detection, then the corrected passing case.
>
> Do not yet implement content, LOD, full mod host or speculative performance features. Do not claim the 4,000 FPS target.
>
> Run formatting, build/lint and focused runner tests. Review the diff. Update progress, environment blockers and handoff with exact commands/results. Return changed files, evidence and the next smallest task.

M0 acceptance: a reproducible reference manifest or explicit blocker, a real environment report, a clean original project skeleton, functioning noninteractive preflight, and honest statuses. A Markdown plan alone does not finish M0.
