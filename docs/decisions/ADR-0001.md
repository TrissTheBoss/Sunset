# ADR-0001 — Custom Rust/WGSL foundation and profiles

Date: 9 November 2026.
Status: ACCEPTED for user-mandated constraints; implementation defaults remain subject to measured revision.

Context: full Java Edition behavior, very high FPS, modding, no first-party C/C++, custom renderer and local resources are required. LOD/upscaling change pixels.

Decision: original safe Rust application with original WGSL rendering; GPU abstraction allowed, complete renderer reuse excluded. Separate Vanilla Fidelity from Enhanced. Establish measurement/extension/ownership infrastructure before mass content, using representative synthetic fixtures. Preserve behavioral rules in both profiles.

Alternatives: existing game renderer rejected by user requirement; GPU-authoritative gameplay rejected for determinism/compatibility risk; strict visual equality with active lossy LOD/upscale rejected as contradictory.

Consequences: significant original engineering; multiple comparison profiles; GLSL packs require extra work; dependency/driver internals still need audit. 4,000 FPS remains measured stretch, not guaranteed.

Reversal: implementation technologies/defaults require a new ADR and relevant tests. User constraints require a user decision to change. No performance evidence yet.
