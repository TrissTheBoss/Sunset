# Core Philosophy

## Product promise

The priority is **100% vanilla Minecraft Java Edition 26.3 parity first; performance second**. Parity includes GUI, movement, physics, client and integrated-server simulation, network protocol, world generation, saves, and baseline rendering. Treat these as required parity surfaces, not optional polish. The target is not a claim that parity has already been achieved. The freeze and evidence inventory is tracked in [issue #1](https://github.com/TrissTheBoss/Sunset/issues/1); secure local import and legitimate-account authentication requirements are tracked in [issue #2](https://github.com/TrissTheBoss/Sunset/issues/2).

## Compatibility and access

The intended target is ordinary authenticated vanilla servers without required server-side modifications. Compatibility presumes a legitimate account entitlement and valid session signing. It cannot guarantee acceptance by every third-party server or compliance with every server operator policy. The project must not bypass authentication. Deviations must be documented as limitations.

## Free for the lifetime of the project

Project functionality remains free: no subscriptions, paid editions, paywalls, or feature gating. This commitment does not imply that hosting, user hardware, network access, or third-party services are free.

## User assets and rights

Users may import assets they provide locally. Local import is not an authentication bypass and does not establish blanket legal permission to extract, use, or redistribute assets. The project must not bundle, redistribute, or fetch copyrighted game assets from unauthorized sources. Keep original code, dependencies, and user-provided content distinct and honor applicable licenses.

## Honest evidence

Describe what was tested, on which versions and conditions, and what remains unknown. Distinguish verified behavior from assumptions. Avoid absolute compatibility statements when test coverage is incomplete. Record significant decisions and their rationale.

## Independence

The project is unofficial. Do not suggest publisher endorsement or affiliation. Use third-party names and marks only as needed to describe compatibility, subject to applicable rights.
