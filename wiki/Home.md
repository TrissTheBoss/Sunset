# Sunset Wiki

Sunset is an independent original Rust/WGSL project targeting Minecraft Java Edition compatibility. This Wiki starter describes planned contracts, not shipped features. Target 26.3 still needs exact artifact verification.

Two goals, in priority order:

1. **Performance:** at least 3,000 FPS on the defined benchmark scene, measured on every change.
2. **Fidelity:** behavior of the pinned target version, proven by differential tests against vanilla.

**Status: planning. No playable build exists yet.**
