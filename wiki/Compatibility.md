# Compatibility

Fidelity targets exact observed Java Edition behavior and native visuals. Enhanced keeps simulation while changing distant geometry/reconstruction. Modded profiles explicitly alter behavior.

Vanilla resource and data packs require exact pinned format semantics. Native WGSL shader packs have a planned Sunset API. Iris/OptiFine packs would require a separate GLSL and render-convention compatibility layer; this is optional future work after milestone M6, and native WGSL support alone does not satisfy that promise.

Server interoperability uses legitimate authentication, protocol and normal gameplay. No guarantee applies to every anticheat or server policy. Testing uses authorized servers; no evasion or authentication bypass.

Parity is tracked per inventory item and test. Passing finite cases is evidence, not proof of every possible behavior. Unsupported or blocked cases are published.
